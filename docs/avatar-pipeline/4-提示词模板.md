# 4. 即梦 / 豆包提示词模板

> 现成可粘贴。结构抄的是 dsh-pet 验证过的那套（通用前缀 + 动作概述 + 按秒分割 + 负向约束），
> 但排版按我们的规格卡重写了。

## 4.0 先纠正生成策略：从「一次赌五个变量」改成「单变量实验」

历史成功率低不是运气问题。一条文生视频同时赌了 5 个变量：

| 变量 | 现在怎么赌 | 锁死手段 |
|---|---|---|
| 角色长相 | 靠文字描述 | **多模态参考**：上传角色图，提示词写 `@图片1 作为主角` |
| 构图位置 | 靠文字描述 | 由参考图本身决定（图里站哪就站哪） |
| 结尾姿态 | 完全交给模型 | **首尾帧模式**：首帧 = 尾帧 = 标准站立锚图，AI 只补中间 |
| 动作幅度 | 靠文字描述 | **动作克隆 / 动作模仿**：传一段参考视频，`@视频1 参考这个动作` |
| 时长 | 一次 10 秒 | 直接设 3~5 秒 |

5 个变量各 0.7 成功率 → 0.7⁵ ≈ 17%。锁死 4 个、只留「动作描述」一个变量 → 成功率贴近单次水平，
而且失败原因一眼能看出来是哪一个变量没锁住。

**入口选择**：豆包对话入口参数少、排队久；即梦是同一家（字节）的完整控制台，
首尾帧、多参考、运镜、时长都在那里。**建议在即梦做**。

> 平台能力会随版本变（当前即梦主线是 Seedance 2.0，支持首尾帧模式、全能参考（多图+多视频）、
> 动作模仿；每日登录赠送 60~100 积分，视频约 1 积分/秒，单次时长上限已扩到 12~15 秒）。
> 动手前先看一眼界面上的实际入口和额度，不要按这里的描述硬找按钮。

## 4.1 通用前缀（固定段，原样粘贴）

> 这段比 dsh-pet 的模板多 6 条硬约束，都是**我们这条管线特有**的（精灵表 360×480、
> 要绿幕抠像、要首尾回锚、所有动作共用一条脚底基线）。逐条理由见 4.1.1。

```
【绝对空间与边界约束强制命令】
视频比例 3:4（平台不支持 3:4 时才用 16:9），背景必须是纯粹的绿幕色
（标准 Chroma Key Green，颜色严格统一为 #00FF00），
无任何阴影、渐变、杂物、边框或地面纹理，背景本身即一整块均匀纯色。

【角色锁定（以参考图为准）】
@图片1 作为主角，全片只出现这一个角色，绝不增减人物。
角色固定为：Q版2.5头身（头部高度约占全身高 40%、头宽大于肩宽、短手臂短腿）、
浅水蓝色长发至肩下（发梢微卷、侧分刘海、头顶一缕呆毛）、深蓝色大眼睛、脸颊圆润、
白色短袖衬衫配深蓝色蝴蝶结领结、深蓝色百褶短裙、黑色过膝长袜、黑色圆头小皮鞋、
日系赛璐璐平涂风格、线条干净闭合、色块分明。
面部、发型、服装、配饰、配色、**头身比例**必须与 @图片1 完全一致，全程不允许变化。

【人物位置与大小（强制固定）】
人物完完全全处于画面正中心偏下：头顶始终在画面垂直方向约 20% 的位置，
脚底始终在画面垂直方向约 85% 的位置，最左/最右边缘始终在水平方向约 20% / 80% 的位置。
【像素高度锁死】角色像素高度必须恒定占画幅高度的 65%，任意两段视频之间角色像素高度差
不得超过 2%；禁止因为动作（跳跃、伸懒腰）而整体放大或缩小角色。
全片不允许任何 X 轴或 Y 轴的整体平移，只允许动作本身带来的肢体位移。
【画幅安全红线】任意一帧，角色任何部位（呆毛、发丝、指尖、裙摆、鞋尖）都必须与画幅
任意一边保持 ≥10% 画幅宽/高的距离，禁止接触、触碰、超出或被裁切。

【动作段纯度（最容易做错的一条）】
整段只演一个动作，并且**只演一次**：眨眼只眨一次、招手只摆两下、点头只点三下。
禁止重复循环同一个动作，禁止在片头或片尾停留在静止站姿超过 0.3 秒。
禁止呼吸起伏、头发飘动、待机晃动等与动作无关的微动，表情变化只允许与这个动作相关。

【朝向与镜像锁死】
全程正面朝向镜头，禁止转身、侧身、回头、镜像翻转、水平翻面
（左右朝向我们自己会在运行时处理）。

【首尾帧约束（最重要）】
第一帧与最后一帧都必须是同一张标准正面站立姿态：双脚并拢站在画面正中，双臂自然垂放贴
身体两侧，双眼睁开平视前方，呆毛挺立，嘴角自然，画面干净无道具无特效、无任何动作残留。
第一帧与最后一帧必须**逐帧一致**（首尾帧模式下把同一张锚图同时设为首帧与尾帧），
表情、手指、发丝、裙摆位置完全相同；中间由你补全动作，动作必须完整回到站姿收尾，
不允许定格在动作中途。
（例外：循环态与睡眠三段的首尾要求见 0-Q版重做执行单 第二节，不要套用这一段。）

【画质与抠像友好】
干净的单色块平涂、清晰线条、无噪点、无胶片颗粒、无后期滤镜、无景深虚化、
无镜头运动（不推拉、不摇移、不旋转、不缩放）。
禁止运动模糊、动态模糊、残影、拖影；
禁止角色在绿幕上产生任何投影、接触阴影、环境光反射或半透明光晕。
全片无文字、无水印、无字幕、无任何字符。
```

### 4.1.1 这 6 条为什么必须有

| 加的约束 | 不加会怎样（我们踩过或量过的） |
|---|---|
| **动作只演一次、静止 ≤0.3s** | 现有 `blink` 有 6.75 秒，其中一半是睁眼站着不动；`nod` 里塞了 3 次点头。多出来的全是废帧，只能事后裁 |
| **像素高度恒定 65%、段间差 ≤2%** | 所有动作共用 360×480 画布和同一条脚底基线。差 2% 以上，换动作时角色会"变大变小" |
| **禁止运动模糊 / 残影 / 绿幕投影** | 抠像留脏边的第一原因。dsh-pet 的模板没提这条，但那是因为它用 PR 手工抠像兜底 |
| **禁止待机微动** | 微动让"首尾回锚"永远达不成，也让差异曲线变成噪声——`blink` 里 f41 那个假眨眼峰就是微动造成的 |
| **禁止转身/侧身/镜像** | 侧面会把重心和脚底基线全部带偏；左右朝向留给运行时翻转，生成时就转反而破坏一致性 |
| **首尾"逐帧一致"而非"姿态相同"** | AI 把"姿态相同"理解成"差不多"，抽帧后尾帧差 5.0 RMS，切回 idle 时姿势会硬跳 |

## 4.2 可变动作段（每次只改这一段）

格式固定：**一句话动作概述** + **按秒分解**。时长写 4 秒（留 1 秒收尾余量）。

```
【动作概述】
角色在原地向右前方举起右手，手掌张开、四指并拢，手腕左右轻摆两下打招呼，
脸上带着浅浅的微笑，眼睛看着镜头。全程双脚不离地、身体不左右移动，
第一帧与最后一帧都是标准正面站立。

【按秒分割画面】
- 0 秒（第一帧）：标准正面站立，双臂自然垂放，双眼平视前方。
- 0~1 秒：右臂抬起至肩高偏上，手肘微屈，手掌张开朝向镜头。
- 1~2.5 秒：手腕以手肘为轴左右轻摆两下，微笑加深，头轻微向右侧歪一点。
- 2.5~3.5 秒：手臂自然放下，回到垂放位置，表情恢复自然。
- 3.5~4 秒：完全静止，与第一帧逐帧一致。
```

## 4.3 睡觉三段接力（当前素材最大的缺口）

现在只有 `sleepy` 一个「趴着循环」的素材在冒充「入睡 + 睡觉 + 醒来」。
按 dsh-pet 的做法拆成**三段**，每段单独生成，接缝处逐帧对齐：

| 段 | 首帧 | 尾帧 | 用途 | 是否回站姿 |
|---|---|---|---|---|
| `sleep_start` | 标准站立 | 睡姿 | 入睡（播一次） | 否 |
| `sleep_loop` | 睡姿 | **与首帧逐帧相同** | 循环 | 否 |
| `sleep_end` | 睡姿 | 标准站立 | 醒来（播一次） | 是 |

**关键差异**（和普通动作的模板不一样，必须改）：

```
【睡觉专用首尾帧规则（强制）】
「睡觉-开始」首帧是标准正面站立、尾帧是睡姿；「睡觉-循环」首帧与尾帧是完全相同的同一睡姿，
必须能无缝循环；「睡觉-起来」首帧是睡姿、尾帧是标准正面站立。
「睡觉-开始」与「睡觉-循环」全程禁止起身、禁止恢复到站立姿态，只有「睡觉-起来」才允许起身。
三段必须共用同一条地面线、同一个角色大小、同一套站立姿势与睡姿描述。

【站立姿势（固定描述，三段共用）】
双脚并拢站在画面正中心，双臂自然垂放，双眼睁开平视前方，呆毛挺立，画面干净无道具，
头顶位于画幅高度 20%、脚底位于 85%。

【睡姿（固定描述，三段共用）】
侧坐在地上蜷成一团打盹，膝盖收在身前，双手合拢垫在脸侧当枕头，呆毛软软垂落，
双眼闭合，身体最低点位于画幅高度约 85%，左右仍居中。
```

**开始段**
```
【动作概述】
第一帧是标准正面站立。角色先打一个大哈欠（张嘴、眼眶泛泪、双臂上举伸懒腰），
随后眼皮越来越沉直到完全闭合，膝盖弯曲、重心缓缓下沉，最后蜷成一团坐着打盹。
最后一帧是睡姿并静止收尾，绝对不许起身、不许恢复站立。

【按秒分割画面】
- 0 秒：标准正面站立，画面干净。
- 0~1.5 秒：张嘴打哈欠，眼眶泛泪，双臂上举伸懒腰，仍在原地站立。
- 1.5~2.8 秒：眼皮沉重下垂直至完全闭合，膝盖弯曲，重心缓缓下沉，呆毛开始下垂。
- 2.8~3.2 秒：完全坐低蜷成一团，双手垫在脸侧，闭眼。
- 3.2~4 秒：保持睡姿，只有极微弱的呼吸起伏，与第 3.2 秒姿态一致。
```
**循环段**
```
【动作概述】
第一帧是睡姿。全段姿势近乎静止，只做极舒缓的呼吸起伏（胸腔与背部缓慢吸气—呼气），
呆毛随呼吸极轻微颤动。最后一帧与第一帧逐帧相同，保证可直接循环、接缝不跳。
全程闭眼，禁止睁眼、禁止起身、禁止位移。

【按秒分割画面】
- 0 秒：睡姿静止，闭眼。
- 0~1.5 秒：缓慢吸气，背部与肩线极轻微抬起。
- 1.5~3 秒：缓慢呼气，身体回到最低点。
- 3~4 秒：呼吸回到起始相位，姿态与第 0 秒逐帧重合。
```
**醒来段**
```
【动作概述】
第一帧是睡姿。前两秒仍蜷着打盹，随后眼睛缓缓睁开、手掌撑地抬起上半身，
伸一个大懒腰（双臂上举、腰背后仰），膝盖发力站起。最后一帧是标准正面站立并完全站定。

【按秒分割画面】
- 0 秒：睡姿，闭眼。
- 0~1.2 秒：保持睡姿，只做极微弱的呼吸起伏。
- 1.2~2.2 秒：眼睛缓缓睁开，手掌撑地，上半身缓缓抬起。
- 2.2~3.2 秒：伸懒腰，双臂上举、腰背后仰，膝盖发力起身，呆毛开始回弹。
- 3.2~4 秒：完全站定，双臂自然放下，呆毛挺立，画面干净无道具。
```

## 4.4 负向约束段（固定，原样粘贴）

```
【禁止项】
禁止：绿幕以外的任何背景元素、阴影、投影、地面、渐变、光斑、粒子、特效、道具；
禁止：文字、字母、数字、水印、字幕、logo、UI、气泡（Zzz 等符号仅睡觉循环段允许且必须淡出）；

禁止：镜头运动（推、拉、摇、移、旋转、变焦）、画幅变化、转场、剪辑、闪白；
禁止：角色整体平移、走出画幅、被裁切、头部或手脚超出安全区；
禁止：服装变化、发型变化、发色变化、脸型变化、头身比例变化、
      画风突变（写实化、3D 化、厚涂化、变回正常头身比）；
禁止：崩坏（多手多脚、手指粘连、五官错位、身体比例突变、脖子拉长、眼睛不对称）；
禁止：运动模糊、动态模糊、残影、拖影、半透明光晕；
禁止：呼吸起伏、头发飘动、待机晃动等与动作无关的微动；
禁止：转身、侧身、回头、镜像翻转、水平翻面；
禁止：同一个动作重复两遍以上；
禁止：定格在动作中途、动作没做完就静止、结尾姿态与第一帧不一致。
```

## 4.5 参数表

| 参数 | 值 | 理由 |
|---|---|---|
| 比例 | 16:9 | 与画幅安全区公式一致；横构图便于站姿居中 |
| 分辨率 | 720p 起步，能选 1080p 更好 | 抽帧后要缩到 360×480，源越高越锐 |
| 时长 | **3~5 秒**（不要 10 秒） | 我们要的动作本身只有 1~3 秒，长视频后半段必然是「站着不动」的废帧 |
| 首帧 | 锚图 | 锁死开场姿态 |
| 尾帧 | **同一张锚图** | 锁死收尾姿态；睡觉三段例外 |
| 参考图 | 锚图（`@图片1`） | 锁死长相与构图位置 |
| 参考视频 | 有就走「动作模仿」 | 锁死动作幅度与节奏，这是最省额度的一招 |

## 4.6 出图 → 入库（命令）

```bash
# 1) 抽帧（12fps 是与现有素材一致的基准）
mkdir -p tmp/frames
ffmpeg -i act_wave.mp4 -vf fps=12 tmp/frames/f%04d.png

# 2) 抠像（你的既有管线：PR 手工 / HSV 自动）。pack 只收已抠好的透明 PNG，
#    未抠像的帧会被质检直接判硬失败（绿幕残留 >1%）。

# 3) 入库：自动按锚图身高缩放 + 脚底基线/中心对齐 + 拼表 + 登记 frames.json
python scripts/avatar-sheet-tool.py pack \
  --from tmp/frames --state wave_b --fps 12 --write

# 4) 质检
python scripts/avatar-sheet-tool.py verify
```

## 4.7 落地检查清单（每条都能自动判定）

| 检查 | 判据 | 谁来做 |
|---|---|---|
| 角色高度一致 | 中位身高与锚图差 ≤ 8% | `verify` 自动 |
| 脚底基线一致 | 首/尾帧 bbox bottom 与锚图差 ≤ 4px | `verify` 自动 |
| 首尾回锚 | 首/尾帧与锚图 SSIM ≥ 0.95 | `verify` 自动（软告警） |
| 抠像干净 | 实心像素里近纯绿占比 ≤ 1% | `verify` 自动（硬失败） |
