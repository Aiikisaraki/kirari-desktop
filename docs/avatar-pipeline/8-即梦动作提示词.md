# 8. 即梦（Seedance）动作提示词 · 重做版

> 本文替代 [6-豆包动作提示词.md](6-豆包动作提示词.md) 作为**当前生成入口**。
> 6 号文档保留作历史（它记录了大量踩坑过程，仍然有效），但打法和约束已按即梦的能力与
> 我们 2026-11 这轮 21 条的实测结果重写。

## 8.0 为什么换一套提示词

即梦比豆包多出四个可用控制项，正好对上旧流程里"靠文字赌"的四个变量：

| 变量 | 旧做法（豆包） | 新做法（即梦） |
|---|---|---|
| 角色长相 | 文字描述 + 参考图 | **多参考图** `@图片1` 锁定 |
| 开场/收尾姿态 | 文字要求"回到站姿" | **首尾帧模式**：首帧=尾帧=锚图 |
| 动作幅度与节奏 | 全部交给模型 | **动作模仿**：传一段参考视频 `@视频1` |
| 角色在画幅里的大小 | 文字写"占 65%" | 由锚图本身决定，且用约束段二次锁死 |

### 这一轮实测出来的四个硬坑（已写进 8.2 约束段）

这四条是 2026-11 用 21 条素材跑完才暴露的，旧文档里没有：

| 坑 | 实测数据 | 后果 |
|---|---|---|
| **跨段体型不一致** | 21 条里 `sleep_end` 站立高 745px、`idle` 638px，**差 17%** | 换动作时角色"忽大忽小"，这是接缝最刺眼的原因之一 |
| **水印位置会移动** | 逐帧扫描：部分帧在底部 y≈898，部分帧跑到顶部 y≈30 | **裁切躲不掉**，必须会员导出时关水印 + 抠像做连通域清理 |
| **idle 里有长段闭眼** | 源 idle 第 20–79 帧（2.5 秒）**全程闭眼** | 待机看着像"犯困"，且闭眼段的画风与睁眼段不一致 |
| **逐帧亮度漂移** | 同一片段内白点亮度 251→224→244，饱和度 62→73 | 播放时肉眼可见"闪一下"，靠后期归一只能补救、不能还原 |

> 结论：**这四个问题在生成阶段用提示词就能避免，事后再修代价极大。**
> 下面 8.2 的约束段每一条都对应上表的一行。

## 8.1 生成参数（每条统一，别改）

| 参数 | 值 | 理由 |
|---|---|---|
| 模式 | **图生视频 → 首尾帧** | 有这个词就一定要用；没有就退到"图生视频"单首帧 |
| 首帧 | `anchor_v1.png` | 锁死开场姿态 |
| 尾帧 | **同一张 `anchor_v1.png`** | 锁死收尾姿态，播完能无跳接回 idle |
| 参考图 | `anchor_v1.png` 作 `@图片1` | 锁死长相、服装、配色 |
| 比例 | **3:4**（没有就 9:16，**不要 16:9**） | 最终画布是 360×480 竖图 |
| 时长 | 一次性动作 **4s**；循环态 **5s** | CLI 的 `--duration` 最小值就是 4；动作本身 1~2.5s，长视频后半段全是废帧 |
| 分辨率 | **1080p** 优先，720p 次之 | 要缩到 360×480，源越高质量越好 |
| 水印 | **关**（会员设置里） | 开着的会烧进画面，且位置会移动 |
| 种子 | 固定一个，全批共用 | 让 20 条尽量落在同一渲染风格上 |

### 首尾帧的四种例外（写错就白跑）

| 类型 | 首帧 | 尾帧 | 关键差异 |
|---|---|---|---|
| 一次性动作（大多数） | 锚图 | **锚图** | 播完要无跳接回 idle |
| **循环态** `idle` / `speak` / `sleep_loop` / `drag_loop` | 各自首帧 | **与首帧逐帧相同** | **绝对不能要求"回站姿"**，否则每圈都有顿挫 |
| `sleep_start` / `sleep_end` | 各自定 | 各自定 | 睡眠是独立动作，**不要求和 idle 衔接**，允许硬切 |
| `drag_start` | 锚图 | `drag_enter_pose.png` | 尾帧不回站姿，停在悬空姿 |

## 8.2 通用约束段（每条提示词都要拼在最前面）

> 比旧版多 5 条，全部针对 8.0 那四个坑。**逐字粘贴**，不要改写。

```
【画幅与背景】
视频比例 3:4。背景是一整块均匀的纯绿色（Chroma Key Green，#00FF00，RGB 0,255,0），
无渐变、无亮斑、无纹理、无地面线、无地平线、无任何杂物。

【角色锁定（以 @图片1 为准）】
@图片1 是主角本人，全片只出现这一个角色，绝不增减人物。
角色固定为：Q版2.5头身（头部高度约占全身高 40%、头宽大于肩宽、短手臂短腿、重心低、敦实可爱）、
冰蓝色长直发（齐刘海覆盖额头，两侧各一缕长发垂到锁骨，长度到胸口，发梢微卷，
**头顶平顺圆弧，没有呆毛、没有发饰**）、深蓝色大眼睛（圆形、瞳孔有明显高光、睫毛清晰）、
脸颊圆润、白色**长袖**衬衫（翻领，袖口到手腕）、领口系深藏青色细带大蝴蝶结、
深藏青色百褶短裙（A 字型，膝上）、**黑色及膝袜**、黑色圆头皮鞋、
日系赛璐璐平涂（干净闭合线稿、色块分明、阴影只有一档硬边）。
面部、发型、发色、服装、配饰、配色、头身比例必须与 @图片1 完全一致，全程不允许任何变化。

【画幅占位（像素高度锁死 —— 针对"跨段体型不一致"）】
角色像素高度必须恒定占画幅高度的 65%，全程每帧都不许变化，偏差超过 2% 即为不合格。
头顶始终在画面垂直方向约 20% 处，脚底始终在约 85% 处，水平居中。
禁止因为动作（跳、举手、伸懒腰）而整体放大、缩小或上下漂移；
只允许动作本身带来的肢体位移。
任意一帧，角色任何部位（发丝、指尖、手肘、裙摆、鞋尖）都必须与画幅四边
各保持 ≥10% 画幅宽/高的距离，禁止接触、贴近、超出或被裁切。宁可画小，不许顶满。

【光照与色彩恒定（针对"逐帧亮度漂移"）】
全片光照、曝光、白平衡、饱和度完全恒定，不允许任何一帧变亮、变暗、变灰、变透。
禁止闪光、闪白、渐隐、渐显、辉光、色温变化。

【眼睛状态（针对"idle 长段闭眼"）】
除提示词明确要求的眨眼之外，**眼睛必须全程睁开平视镜头**。
眨眼只允许发生一次、持续不超过 0.2 秒，禁止长时间闭眼、禁止半闭、禁止犯困表情。

【动作纯度】
整段只演一个动作，并且只演一次。禁止重复循环同一动作，
禁止在片头或片尾停留静止超过 0.3 秒，
禁止与动作无关的呼吸起伏、头发飘动、待机晃动。

【朝向】
全程正面朝向镜头，禁止转身、侧身、回头、镜像翻转、水平翻面。

【首尾帧约束】
第一帧与最后一帧都必须是同一张标准正面站立姿态（首尾帧模式上传同一张锚图）：
双脚并拢站在画面正中，双臂自然垂放贴身体两侧，双眼睁开平视前方，嘴角自然，
画面干净无道具无特效、无动作残留。首帧与尾帧必须逐帧一致，动作必须完整回到站姿。
（例外：循环态与睡眠三段见 8.1 的「四种例外」。）

【画质与抠像友好（针对"水印"和"绿幕投影"）】
干净的单色块平涂、清晰线条、无噪点、无胶片颗粒、无后期滤镜、无景深虚化。
禁止运动模糊、动态模糊、残影、拖影、半透明光晕。
禁止角色在绿幕上产生任何投影、接触阴影、环境光反射。
全片无文字、无水印、无字幕、无任何字符、无 logo。
```

### 8.2.1 如果即梦有「动作模仿」，优先用它

对 `wave` / `nod` / `shake` / `bow` / `happy` / `excited` 这 6 个节奏型动作，
如果你手上有旧素材（现有 `resources/official-avatars/kirari/*.png` 拼成的视频片段），
可以直接传进去当 `@视频1`，提示词写「@视频1 只作为动作幅度与节奏的参考，不要参考它的画风和长相」。
这是**最省额度、成功率最高**的用法：动作变量锁死后，只剩下"长相"一个变量。

## 8.3 20 条动作提示词

> 用法：**8.2 通用约束段** + 下面这一条，整段粘贴。
> 每条的动作弧线按 2.5~3 秒写完，**但请把生成时长设为 4 秒**（CLI 的 `--duration` 最小值就是 4，写 3 会直接报错）。
> 多出来的 1 秒是静止尾巴，入库时用 `pack --auto-trim` 自动切掉，不会进入精灵表。

### 批次 B · 基础循环（先跑这 3 条，验证通过再批量）

#### 01 `idle` 待机（循环 · 5s）

```
【首尾帧】首帧与尾帧使用同一张图，必须逐帧完全相同，可直接循环、接缝不跳。
【动作】角色原地自然站立，做一次极缓慢的完整呼吸：胸腔与肩线缓慢上抬再回落，
第 2 秒在吸气最高点轻眨一次眼（仅此一次），其余部位完全不动。
【按秒】0s 站姿静止；0~2s 缓慢吸气、肩线轻微上抬、第 2s 眨眼一次；
2~4s 缓慢呼气、肩线回落；4~5s 回到与第 0 秒逐帧重合的相位。
【本段额外禁止】闭眼超过 0.2 秒；身体左右晃；换重心；手臂摆动。
```

#### 02 `speak` 说话（循环 · 5s）

```
【首尾帧】首帧与尾帧使用同一张图，必须逐帧完全相同，可直接循环、接缝不跳。
【动作】角色原地说话：嘴巴开合，每 0.3 秒一次，幅度自然；
头部随语调做极轻微的点动（幅度不超过 3 度）；双手保持垂放不动；全程眼睛睁开。
【按秒】0s 闭嘴；0~4s 持续开合说话 + 极轻微点头；4~5s 逐渐收回与第 0 秒相同的闭嘴姿态。
【本段额外禁止】手臂抬起；肩膀耸动；大幅转头；闭眼。
```

#### 03 `sleep_loop` 睡着（循环 · 5s）※ 先跑这条，之后要抽睡姿帧

```
【首尾帧】首帧与尾帧使用同一张图（睡姿图），必须逐帧完全相同，可直接循环、接缝不跳。
【画幅占位】角色整体（含头顶头发、两侧发梢、手肘、膝盖、鞋尖鞋跟）高度只占画幅高度 55%~60%，
宽度不超过画幅宽度 70%，水平居中。四边各留 ≥15% 纯绿空白。
必须完整可见、不许被裁：头顶与整个发型、双手、膝盖、两只鞋。
鞋底与画幅底边之间必须还能看到一条绿色空白。
【动作】角色侧坐在地上蜷成一团打盹：膝盖收在身前，双手合拢垫在脸侧当枕头，
长发自然垂在身体两侧、全部在画幅内，双眼闭合，只做极舒缓的呼吸起伏。
【按秒】0s 睡姿静止；0~2s 缓慢吸气、背部肩线微抬；2~4s 缓慢呼气回落；
4~5s 回到与第 0 秒逐帧重合。
【本段额外禁止】睁眼、起身、站立、走动；姿势大幅变化；Zzz 等符号。
```

> **出图验收（不对就重抽，别拿去抠像）**：两只鞋完整且鞋底下还有绿 / 两侧长发都在画内 /
> 头顶上方 ≥10% 绿 / 四角干净 / 角色只占画幅一半多一点 / 背景均匀纯绿。

### 批次 C · 高频一次性动作

#### 04 `wave` 招手

```
【动作】角色原地举起右手到肩高偏上，手掌张开四指并拢，手腕以手肘为轴左右轻摆两下打招呼，
嘴角上扬、眼睛看着镜头。双脚不离地、身体不左右移动。
【按秒】0s 站姿双臂垂放；0~0.6s 右臂抬到肩高偏上、手掌朝镜头；
0.6~1.6s 手腕左右轻摆两下、微笑加深；1.6~2.4s 手臂放下回垂放；
2.4~3s 完全静止，与第一帧逐帧一致。
【本段额外禁止】低头；耸肩；另一只手跟着动。
```

#### 05 `nod` 点头

```
【动作】角色原地轻轻点头三次，幅度小而干脆，下巴下低约 10~15 度，
眼神保持看镜头，表情认真温和，身体和手臂不动。
【按秒】0s 站姿；0~0.2s 下巴微收；0.2~1.4s 连续点头三次、每次约 0.4 秒、节奏均匀；
1.4~2.4s 头回到正中、表情放松；2.4~3s 完全静止，与第一帧逐帧一致。
【本段额外禁止】上半身前倾或鞠躬；闭眼；脖子拉长。
```

#### 06 `happy` 开心跳一下

```
【动作】角色原地开心地向上蹦一下（双脚离地约 10 像素），落地后笑开，双手轻握在胸前。
跳起时角色整体上移，但水平位置不动，头顶不能超出画幅。
【按秒】0s 站姿；0~0.4s 微微下蹲蓄力；0.4~0.9s 向上跳起、双脚离地、笑开；
0.9~1.4s 落地、双脚回到地面；1.4~2.4s 站着笑、双手轻握胸前；
2.4~3s 完全静止，与第一帧逐帧一致。
【本段额外禁止】左右平移；旋转翻滚；头顶超出画幅；落地后再次起跳。
```

#### 07 `bow` 鞠躬

```
【动作】角色原地鞠躬：上半身向前倾约 30 度，停半秒，再直起身回到站姿。双脚不离地。
【按秒】0s 站姿；0~0.6s 上身向前倾约 30 度、双手贴在身前；0.6~1.2s 保持鞠躬；
1.2~2.0s 直起身、双手回到身体两侧；2.0~3s 完全静止，与第一帧逐帧一致。
【本段额外禁止】膝盖跪地或蹲下；低头超过鞠躬角度；闭眼。
```

#### 08 `head_tilt` 歪头倾听

```
【动作】角色把头向一侧歪约 15 度，眼睛看着镜头，像在认真听人说话，停一秒后回正。
身体和手臂不动，表情柔和专注。
【按秒】0s 站姿正视镜头；0~0.5s 头向一侧缓慢歪约 15 度、眼睛看镜头；
0.5~1.6s 保持歪头、轻眨一次眼；1.6~2.4s 头回正、表情恢复自然；
2.4~3s 完全静止，与第一帧逐帧一致。
【本段额外禁止】说话口型；手臂动作；身体跟着倾斜；闭眼超过 0.2 秒。
```

### 批次 D · 情绪

#### 09 `excited` 兴奋

```
【动作】角色原地快速小跳两下，双手在身前快速摆动，眼睛发亮、笑得很开。
跳起时水平位置不动，头顶不能超出画幅。
【按秒】0s 站姿；0~0.8s 快速小跳一下、双手上摆；0.8~1.6s 再跳一下、双手再摆；
1.6~2.4s 落地站定、笑容收小；2.4~3s 完全静止，与第一帧逐帧一致。
【本段额外禁止】连跳三下以上；左右平移；旋转。
```

#### 10 `sad` 难过

```
【动作】角色低下头、肩膀下沉、双手垂在身前轻轻交握，头发也跟着垂落，眼神向下。
动作缓慢，不要哭、不要掉眼泪。
【按秒】0s 站姿；0~0.8s 头缓慢低下、肩膀下沉；0.8~2.0s 双手在身前交握、眼神向下；
2.0~3s 慢慢抬起头、肩膀抬起、手放下，回到与第一帧一致。
【本段额外禁止】下蹲跪地；眼泪泪滴特效；画面整体变暗。
```

#### 11 `shy` 害羞

```
【动作】角色脸颊泛红，双手抬到胸前轻轻绞在一起，头微低并向一侧偏，
眼神躲开镜头又偷看一下。红晕只在脸颊，不要变成夸张特效。
【按秒】0s 站姿；0~0.7s 双手抬到胸前绞在一起、脸颊泛红、头微低偏一侧；
0.7~1.9s 保持害羞姿态、偷看镜头一眼；1.9~2.7s 双手放下、头回正、脸红退去；
2.7~3s 完全静止，与第一帧逐帧一致。
【本段额外禁止】爱心符号；气泡符号；闭眼超过 0.2 秒。
```

#### 12 `surprised` 惊讶

```
【动作】角色肩膀猛地一缩、上身轻微后仰、眼睛睁大、嘴巴张开一点，
随后慢慢放松回站姿。双脚不离地、不后退。
【按秒】0s 站姿；0~0.3s 肩膀猛缩、上身微后仰、眼睁大、嘴张开；
0.3~1.0s 保持惊讶、眨一次眼；1.0~2.0s 慢慢放松、肩落、上身回正；
2.0~3s 完全静止，与第一帧逐帧一致。
【本段额外禁止】后退走出画幅；感叹号等符号特效；夸张变形。
```

#### 13 `shake` 摇头

```
【动作】角色原地摇头三次，幅度小、节奏干脆，眉头微皱，身体不动。
【按秒】0s 站姿；0~0.2s 头开始转向一侧；0.2~1.4s 连续摇头三次、每次约 0.4 秒；

```

#### 14 `thinking` 思考

```
【动作】角色头微低、一只手抬到下巴处轻触，眼神飘向斜上方，缓慢眨两次眼，像在想事情。
【按秒】0s 站姿；0~0.7s 头微低、右手抬到下巴轻触、眼神上飘；
0.7~2.2s 保持思考、缓慢眨两次眼、头极轻微左右晃一下；
2.2~3s 手放下、头抬起、眼神回到镜头。
【本段额外禁止】问号、灯泡、齿轮等符号；手臂大幅挥动。
```

#### 15 `angry` 生气

```
【动作】角色鼓起腮帮、眉头皱起、双臂抱在胸前，头转向一侧表示不满，
随后慢慢放下手臂、松开眉头回到站姿。
【按秒】0s 站姿；0~0.6s 双臂抬起交叉抱在胸前、鼓起腮帮、皱眉、头偏向一侧；
0.6~2.0s 保持抱臂鼓腮、头轻轻扭一下、眼睛半闭；
2.0~3s 手臂放下、脸颊恢复、头转回正中。
【本段额外禁止】头顶冒烟、怒气符号、爆炸特效；面部扭曲夸张。
```

#### 16 `attention` 举手引起注意

```
【动作】角色抬起一只手在头顶前方挥两下，同时踮起脚尖，像在说「看我这里」，
表情期待、眼睛看着镜头。
【按秒】0s 站姿；0~0.5s 右手抬到头顶前上方、踮起脚尖；
0.5~1.6s 手腕在头顶前方挥两下、表情期待；1.6~2.4s 手放下、脚跟落地；
2.4~3s 完全静止，与第一帧逐帧一致。
【本段额外禁止】跳起；头顶超出画幅；脚离地。
```

#### 17 `stretch` 伸懒腰

```
【动作】角色双臂上举过头、腰背轻微后仰伸个懒腰，眼睛闭上、嘴微张，
保持一秒后放松、手臂放下、睁眼。
【按秒】0s 站姿；0~0.8s 双臂上举过头、腰背后仰、闭眼；
0.8~2.0s 保持伸懒腰、胸腔上提；2.0~3s 手臂放下、身体回正、睁眼，回到与第一帧一致。
【本段额外禁止】手或头顶超出画幅；踮脚；身体左右移动。
```

#### 20 `drag_start` 进入拖动（尾帧 = drag_enter_pose.png）

> 这条踩过 6 次坑，别再改叙事：**根因是"施力者叙事"**——只要描述里暗示有外力把她弄上天，
> 视频模型就一定把施力者（手/绳/钩）画出来。第 6 版改成「**她自己轻轻一蹦浮起**」后彻底解决。

```
【首尾帧】首帧使用 @图片1（标准站姿），尾帧使用 @图片2（悬空姿），
最后一帧必须与 @图片2 逐帧一致。
【场景】桌宠从站姿切换到悬空拖拽姿势的一次性短过渡，播完接 drag_loop 循环。
【参考】@图片1 是主角本人，首帧站姿使用这张图；
@图片2 是悬空目标姿势（尾帧），长相服装以 @图片1 为准，姿势严格照抄。
【动作】第一帧是标准正面站姿。她深吸一口气，**自己**轻轻向上一蹦，双脚离地浮在半空
——这是她自己完成的动作，不靠任何东西。
浮起后把姿势收成 @图片2：身体端正不歪、肩膀微耸，双手自然垂在身体两侧、手指收拢，
两腿并拢微弯、脚尖朝下，头发裙摆自然垂落。
【最关键】最后一帧必须是 @图片2 的原样 —— 身体正对镜头、不歪头、不倾斜，
双手仍在身体两侧不要往斜下方伸，表情是抿嘴紧张（不是张嘴惊讶）。
最后 1 秒就停在 @图片2 这个姿势上，不再变化、不再飘动。
【按秒】0s 标准站姿双脚着地；0~0.8s 自己轻轻一蹦、双脚离地；
0.8~1.8s 收成 @图片2 的悬空姿势；1.8~3s 保持 @图片2 姿势不动。
【画面里应该看到】她一个人；她的两只手都在自己身体两侧；其余是干净纯绿背景。
【本段额外禁止】手臂张开摊平；身体歪斜或后仰漂浮；头发裙摆向上飘；落地回站姿；
任何绳子、线、钩子、杆子、从画面外伸进来的手。
```

**骨架自检**：量三个宽度 —— 肩宽、肘宽、站距。正常应是 **肘宽 ≤ 肩宽**、站距明显小于肩宽。
若肘宽 > 肩宽，就是手臂张开了，重抽。

#### 21 `drag_loop` 悬空循环（5s）

```
【场景】桌面宠物被按住拖动时全程循环播放的动画，窗口跟着鼠标走，她在窗口里保持悬空姿势。
第一帧就必须是悬空姿势，全程都是这个姿势，不出现站在地面或从站姿升起的画面。
【首尾帧】首帧与尾帧都使用 @图片2（drag_enter_pose.png），必须逐帧完全相同，可直接循环。
【姿势】她被拎在半空，整个人缩着、有点紧张：肩膀微耸、脖子略缩、身体收紧；
双臂自然垂着贴近身体两侧，手握拳或手指收拢，不要张掌、不要向两侧伸开；
两腿并拢、膝盖微弯、脚尖朝下，脚离地；头发和裙摆像站着时一样自然垂下，不飘起；
眼睛睁着看前方，表情紧张又无奈，不是微笑、不是发呆。
画面里只有她自己，周围没有任何东西。
【动作】保持姿势，只做很小幅度的左右晃动，像被拎着的东西那样轻轻摇。位置和高度不变，身体不前后仰。
【按秒】0s 悬空姿势；0~1.25s 轻轻晃向一侧再回正；1.25~2.5s 晃向另一侧再回正；
2.5~5s 重复一遍，第 5 秒与第 0 秒逐帧重合。
【本段额外禁止】站在地面、从站姿起飞、缓缓离地；手臂张开、手心摊开朝上；
身体后仰摊开；头发裙摆飘起；任何绳子线钩杆；落地回站姿。
```

## 8.4 每条的验收（不过就重抽，别将就）

## 8.6 执行顺序（照这个跑，别跳）

1. **先确认锚图**：`anchor_v1.png` 必须是绿幕底、Q 版 2.5 头身、占据画幅 65%。不符合就先重出锚图。
2. **跑批次 B 的 3 条**（idle / speak / sleep_loop）。这 3 条决定后面 17 条要不要跑——
   如果循环接缝跳、体型不稳、或者有闭眼废帧，说明锚图或约束段有问题。
3. **从 `sleep_loop` 抽一帧睡姿**存成 `sleep_pose.png`。
4. **跑批次 C/D**（wave/nod/happy/bow/head_tilt + 7 个情绪），这 12 条共用一条锚图。
5. **用 `sleep_pose.png` 跑 `sleep_start` / `sleep_end`。**
6. **跑 `drag_loop`**，抽首帧存成 `drag_enter_pose.png`。
7. **用 `drag_enter_pose.png` 跑 `drag_start`**（尾帧）。
8. **`blink` 不生成** —— 从 `idle` 素材里裁一次「闭眼→睁眼」，零成本且画风绝对一致。
9. 入库：抽帧 → 抠像 → `clean`（连通域去水印 + 去软阴影）→ `pack` → `verify`。

> 第 2 步不要省。旧流程最大的浪费就是"锚图不对还一口气跑完 20 条"。
