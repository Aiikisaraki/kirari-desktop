# 0. Q 版重做执行单

> 决定：**整套重做**，理由是现有素材是 6~7 头身的成年比例，不像桌宠。
> 这份是执行单，从上往下做：锚图 → 基础循环 → 一次性动作 → 入库。
> 提示词的通用前缀/负向段见 [4-提示词模板.md](4-提示词模板.md)，这里只写"重做专用"的差异。

## 一、规格基准（先钉死，否则 21 条素材各画各的）

| 项 | 现在 | 重做目标 | 为什么 |
|---|---|---|---|
| 头身比 | ~6.5 头身 | **2.5 头身**（头高 ≈ 总高 40%，头宽 > 肩宽） | 这是"不像桌宠"的根因 |
| 画布 | 360×480 | **360×480 不变** | 渲染器、逐像素点穿、窗口全部零改动 |
| 角色高度 | 458px（占画布 95%） | **390px（81%）** | 头顶只剩 15px 时，跳跃/举手过头会出画被切 |
| 头顶 / 脚底 | y=15 / y=473 | **y≈83 / y=473** | 脚底基线不变，上方留 83px 给跳跃 |
| 站立宽度 | 116px | **≈200px**（头宽 ≈190） | Q 版头大，横向占位自然变宽 |
| 动作最大宽度 | 258px | **≤330px** | 招手/伸懒腰展开手臂时左右各留 15px |
| 生成画幅 | 16:9 | **3:4 优先**（不支持就 16:9） | 我们最终是 3:4 画布，3:4 生成能给角色更多像素 |
| 生成时长 | 10s | **3~5s** | 动作本身 1~3s，长视频后半段必是废帧 |
| 抽帧 | 12fps | 12fps 不变 | 与现有渲染节奏一致 |
| 一次性动作时长 | 4~6s | **1.2~2.5s** | 见 [1-素材规格卡.md](1-素材规格卡.md) |
| 循环态时长 | 10~12s | **6~12s** | idle 可以长，speak 6s 够 |

**「2.5 头身」怎么写进提示词**：不要只写"Q 版"，AI 会给你 4 头身。要写数字 + 参照物：

```
Q版2.5头身，头部高度约占总身高的 40%，头部宽度大于肩宽，短手臂短腿，
大眼睛约占脸部的三分之一，脸颊圆润，站立时重心低、看起来敦实可爱。
```

## 二、三处最容易做错的差异（做错就白跑一次）

| 素材类型 | 首帧 | 尾帧 | 提示词里必须写的那一句 |
|---|---|---|---|
| **一次性动作**（wave/nod/happy…） | 锚图 | **同一张锚图** | 「首帧与尾帧逐帧一致，动作必须完整回到站姿」 |
| **循环态**（idle/speak/sleep_loop） | 循环首帧图 | **与首帧逐帧相同** | 「最后一帧与第一帧逐帧重合，可直接循环，接缝不跳」——**不能要求回站姿** |
| **睡眠三段** | start: 站姿→睡姿；loop: 睡姿→睡姿；end: 睡姿→站姿 | — | 「开始与循环段禁止起身，只有起来段才允许站」 |

> 循环态如果也要求"尾帧回站姿"，AI 会给你一段"站着→动一下→回站姿"的视频，
> 循环播放时每一圈都能看到回站姿的顿挫。这是最容易踩的坑。

**睡眠三段不要求首帧回锚，也不需要和 idle 衔接**（2026-11-03 拍板）：睡眠是一个相对独立的动作，
允许直接切换，**连交叉溶解都不需要**。唯一的要求是它自己能循环起来 —— `sleep_loop` 首尾一致即可，
`sleep_start` 首帧站姿、尾帧睡姿，`sleep_end` 反过来。
所以睡眠素材的验收里**没有"首尾回锚 SSIM ≥0.95"这一项**（`verify` 对 loop 态只看首↔尾），
换来的是给它更多画幅余量：宁可角色画小，也不许贴着画幅边缘。

**但睡姿有一条硬约束：不许出框，且头不能变大。** 坐/蜷的姿势包围盒高度和站姿差不多，
按"角色高 = 锚图高 390px"缩放会把头放大 10%（实测睡姿缩完头宽 198px，锚图是 180px）。
姿势变化大的素材必须用 `pack --scale-by head`，按头宽对齐：缩放后占位 275×357，
四边留白 43/42/113/10，头顶/手肘/鞋尖都在画幅内。

## 四、动作提示词：模板 + 示例

每条 = 【通用前缀（见 4 号文档）】+【动作概述】+【按秒分割画面】。
**首尾帧模式下，首帧图与尾帧图都传同一张锚图**（循环态传循环首帧图，见第二节）。

### 一次性动作示例（挥手）

```
【动作概述】
角色在原地举起右手到肩高偏上，手掌张开、四指并拢，手腕左右轻摆两下打招呼，
嘴角上扬、眼睛看着镜头。双脚不离地、身体不左右移动。
第一帧与最后一帧都是标准正面站立，动作只演一次，不重复。

【按秒分割画面】
- 0 秒（第一帧）：标准正面站立，双臂自然垂放。
- 0~0.6 秒：右臂抬起至肩高偏上，手肘微屈，手掌朝向镜头。
- 0.6~1.6 秒：手腕以手肘为轴左右轻摆两下，微笑加深。
- 1.6~2.2 秒：手臂自然放下，回到垂放位置，表情恢复自然。
- 2.2~3 秒：完全静止，与第一帧逐帧一致。
```

### 循环态示例（待机 idle / 说话 speak / 睡觉循环）

```
【动作概述】
角色原地站着，身体以极轻微的幅度缓慢呼吸起伏（胸腔与肩线缓慢上抬—回落），
呆毛随呼吸极轻微晃动，眼睛偶尔眨一下，其余部位不动。
第一帧与最后一帧必须逐帧完全相同，可直接循环播放、接缝处不跳。
禁止位移、禁止转身、禁止出现动作幅度大的手势。

【按秒分割画面】
- 0 秒（第一帧）：标准正面站立，自然表情。
- 1~3 秒：缓慢吸气，肩线轻微上抬，呆毛微晃。
- 3~5 秒：缓慢呼气，身体回落。
- 5~6 秒：呼吸回到起始相位，姿态与第 0 秒逐帧重合。
```

说话态把「偶尔眨眼」换成「嘴巴开合说话（约每 0.3 秒一次），头部随语调轻微点动」，
其余不变。睡觉循环把「站立」换成睡姿描述、并去掉位移。

### 其余动作的「动作概述」一句话（套进同一个模板）

| 状态 | 一句话动作概述 | 目标时长 |
|---|---|---|
| `blink` | 角色原地眨一次眼：眼睑快速合上再张开，其余部位完全不动 | 0.3s**（见注）** |
| `nod` | 角色原地轻轻点头三次，幅度小、节奏干脆，表情认真温和 | 1.2s |
| `happy` | 角色原地开心地向上蹦一下（双脚离地约 10px），落地后笑开，双手轻握在胸前 | 2.0s |
| `bow` | 角色原地鞠躬：上身向前倾约 30°，停半秒，再直起身 | 1.6s |
| `head_tilt` | 角色把头向一侧歪约 15°，眼睛看着镜头，像在认真听，停一秒后回正 | 1.6s |
| `excited` | 角色原地快速小跳两下，双手在身前快速摆动，眼睛发亮、笑得很开 | 2.0s |
| `sad` | 角色低下头、肩膀下沉、双手垂在身前交握，呆毛也跟着垂下来 | 2.4s |
| `shy` | 角色脸颊泛红，双手抬到胸前轻轻绞在一起，头微低并向一侧偏 | 2.0s |
| `surprised` | 角色肩膀猛地一缩、上身轻微后仰、眼睛睁大、嘴巴张开一点，随后放松回站姿 | 1.4s |
| `shake` | 角色原地摇头三次，幅度小、节奏干脆，眉头微皱 | 1.2s |
| `thinking` | 角色头微低、一只手抬到下巴处轻触，眼神飘向斜上方，缓慢眨两次眼 | 2.4s |
| `stretch` | 角色双臂上举过头、腰背后仰伸个懒腰，眼睛闭上，随后放松放下手臂 | 3.0s |
| `angry` | 角色鼓腮、皱眉、双臂抱在胸前，头转向一侧扭头不理人 | 2.0s |
| `attention` | 角色抬起一只手在头顶前方挥两下，同时踮起脚，像在说「看我这里」 | 1.6s |
| `drag_start` | 被从后领拎起来：站姿 → 双脚离地 → 悬空晃动。**尾帧停在悬空，不回站姿**（一次性过渡） | 2.0s |
| `drag_loop` | 悬空状态下的钟摆式轻晃，脚始终不落地、高度恒定、只有摆动没有位移。**首尾逐帧一致可循环** | 2.5s 循环 |
| `sleep_start` | 打哈欠（张嘴、双臂上举伸懒腰）→ 眼皮沉重闭合 → 膝盖弯曲重心下沉 → 蜷成一团坐着打盹。**尾帧是睡姿，禁止起身** | 4s |
| `sleep_end` | 保持睡姿 → 睁眼 → 手掌撑地抬起上身 → 伸懒腰 → 站起。**尾帧是标准站姿** | 4s |

> **注**：`blink` 不要真去生成 3 秒视频。眨眼只有 2~4 个有效姿态，生成一次 3 秒的眨眼
> 视频，抽帧后仍然要挑帧。**推荐做法是直接从 `idle` 素材里裁**——idle 本身就会眨眼，
> 把一次「闭眼→睁眼」的片段单独切出来当 `blink`，代价为零，而且和 idle 是同一次生成、
> 画风完全一致。这也是现有素材被裁成 0.29s 的那套做法。

## 五、分批与额度

| 批次 | 内容 | 条目 | 说明 |
|---|---|---|---|
| A | **锚图** | 1 张图 | 反复抽，满意为止（图比视频便宜太多） |
| B | 基础循环 | 3 | `idle` / `speak` / `sleep_loop` — 首尾相同的循环态，先跑这 3 条验证"循环接缝" |
| C | 高频一次性动作 | 5 | `wave` / `nod` / `happy` / `bow` / `head_tilt` |
| D | 情绪 | 6 | `excited` / `sad` / `shy` / `surprised` / `shake` / `thinking` |
| E | 睡眠与人形互动 | 6 | `sleep_start` / `sleep_end` / `drag_start` / `drag_loop` / `angry` / `attention`（拖动必须两条：一条过渡 + 一条循环，否则拖久了会僵住） |
| F | 补 | 1 | `stretch`（也可从 `sleep_start` 前 2 秒切） |
| — | `blink` | 0 | **从 idle 裁**，不单独生成 |

合计 **20 条视频 + 1 张锚图**。按 3~5 秒/条约 3~5 积分算，理想情况 80 积分上下；
按历史废稿率 50~70% 估，实际约 **130~170 积分**（每日赠送 60~100，约 2 天）。
平台价格与额度会变，动手前看一眼当前规则。

**不要一次全跑完。** 先跑批次 B（3 条），确认「循环接缝不跳、画风一致、比例对」，
再批量跑 C/D/E。B 跑歪了说明锚图或提示词有问题，这时候后面 17 条还没烧。

## 六、入库（每条素材落地）

```bash
# 1) 抽帧
mkdir -p tmp/act_wave
ffmpeg -i wave.mp4 -vf fps=12 tmp/act_wave/f%04d.png

# 2) 抠像（ffmpeg chromakey+despill 或 PR 手工），输出透明 PNG 到 tmp/wave_keyed/

# 3) 清理残留（必做）：连通域去水印 + 贴核心去软阴影
python scripts/avatar-sheet-tool.py clean --from tmp/wave_keyed --to tmp/wave_clean --write

# 4) 入库：按锚图身高统一缩放 + 脚底/中心对齐 + 自动切掉末尾静止帧 + 拼表 + 登记
python scripts/avatar-sheet-tool.py pack \
  --from tmp/wave_clean --state wave --fps 12 --auto-trim --write

# 4) 质检（硬失败会返回非 0）
python scripts/avatar-sheet-tool.py verify
```

`--auto-trim` 会自动切掉「动作演完之后站着不动」的尾巴（实测末段连续 ≥3 帧帧间差 <1.5 → 切）。
生成 3~5 秒视频时动作通常 2 秒就做完了，这一步能省掉 30~50% 的帧。

## 七、每批的验收清单

| 检查 | 判据 | 谁判 |
|---|---|---|
| 头身比 | 与新锚图一致（不像"长大了"） | 人眼 |
| 身高/基线 | 与锚图差 ≤8% / ≤4px | `verify` 自动 |
| 首尾回锚 | 一次性动作 SSIM ≥0.95 | `verify` 自动（新素材应达得到） |
| 循环接缝 | 循环态首帧与尾帧 SSIM ≥0.95 | `verify` 自动 |
