> （跨段体型差 17% / 水印位置移动 / idle 长段闭眼 / 逐帧亮度漂移），
> 并改用即梦的首尾帧 + 多参考 + 动作模仿。

> 那些结论在 8 号文档里仍然有效。

## 使用步骤

1. 豆包 → 视频生成
2. 上传 `anchor_v1.png` 当参考图
3. 有首帧/尾帧选项时，**两张都选 `anchor_v1.png`**（循环态、`sleep_*`、`drag_start` 例外，见下）
4. 比例 **3:4**（没有就 9:16，别选 16:9）；时长 **5 秒**（能选 3 秒更好）
5. 粘一条提示词 → 生成 → 下载

## 五个必须知道的例外

| 类型 | 首帧 | 尾帧 | 为什么 |
|---|---|---|---|
| 一次性动作（大多数） | 锚图 | 锚图 | 播完要能无跳地接回 idle |
| **循环态**（`idle` / `speak` / `sleep_loop` / `drag_loop`） | 各自首帧 | **与首帧相同** | 循环态不能回站姿再停，否则每圈都有顿挫 |
| **`drag_start`**（一次性） | 锚图 `@图片1` | **`drag_enter_pose.png`** = `@图片2`（悬空姿，不回站姿） | 它是「站姿→悬空」过渡；写成**她自己浮起**，绝不写被拎/被拿，否则豆包必画施力者 |
| **`drag_loop`**（循环） | 悬空姿态（= `drag_enter_pose.png`） | **与首帧相同** | 拖动时长不定（可能十几秒），只有循环才不会僵住；**首尾必须逐帧一致** |
| **`sleep_*`（睡眠三段）** | 各自定 | 各自定 | **睡眠是独立动作，不要求和 idle 衔接**。允许直接切换，连交叉溶解都不需要；`sleep_loop` 唯一的要求是自己首尾一致、能循环。所以这三条提示词里完全不提"回站姿/回锚图" |

## 五个「先生成、再反哺」的依赖

1. `blink` **不生成** —— 直接从 `idle` 里裁一次「闭眼→睁眼」（零成本，画风绝对一致）
2. `sleep_loop` **先生成** → 从视频里抽一帧睡姿存成 `sleep_pose.png`
3. `sleep_start` 的**尾帧** = `sleep_pose.png`
4. `sleep_end` 的**首帧** = `sleep_pose.png`
5. `drag_loop` **先生成** → 抽首帧存成 `drag_enter_pose.png` → 作为 `drag_start` 的**尾帧**
   （`drag_enter_pose.png` 与 `drag_loop` 首帧同源；2026-11-18 从 drag_start 实际生成帧重抽，
   替换了豆包画不出来的旧 `drag_pose.png`。旧图留作历史参考，不再用于生成。）

所以批次 B 跑完、睡姿帧拿到之后，才能做 `sleep_start` / `sleep_end`；
`drag_loop` 入库后才能做 `drag_start`。

## 01 `idle` 待机（循环）

```
【参考】@图片1 是主角本人，首帧与尾帧都使用这张图。
【保持】Q版2.5头身、冰蓝长发齐刘海（无呆毛无发饰）、深蓝色大眼、白色长袖衬衫配深蓝色大蝴蝶结、
深蓝色百褶短裙、黑色及膝袜、黑色圆头皮鞋，全部不变；纯绿幕背景不变；
角色居中不位移；镜头固定，不推拉不摇移不旋转。
【动作】角色原地站着，以极轻微幅度缓慢呼吸起伏，眼睛偶尔眨一下，其余部位不动。
最后一帧必须与第一帧逐帧完全相同，可直接循环播放、接缝处不跳。
【按秒】0s 标准站姿；1~3s 缓慢吸气、肩线轻微上抬；3~5s 缓慢呼气回落；
5~6s 回到起始相位，与第 0 秒逐帧重合。
【禁止】整体平移、转身、侧身、镜像；动作幅度大的手势；运动模糊与残影；
绿幕上出现投影或地面线；文字水印；镜头运动；同一个动作重复两遍。
```

## 03 `sleep_loop` 睡着（循环）※ 先跑这条，之后要抽睡姿帧

> **2026-11-03 重写**。上一版翻车了：豆包把角色画得顶满画幅，**鞋子被下边缘切掉、两侧长发被左右边缘切掉**。
> 根因是旧提示词写了「身体最低点与站立时脚底处于同一水平位置」——这句话会把它往画幅底部按，
> 而且只说"留白 10%"没给具体占位数字，模型会忽略。
> 新版把**占位写成一个可判定的数字（55%~60%）**，并且**逐项点名**哪些部位不许出画。
>
> 另外：睡眠是独立动作，**不需要和 idle 衔接**（允许直接切换，连交叉溶解都不需要），
> 唯一要求是它自己首尾一致、能循环。所以这条提示词里完全不提"回站姿/回锚图"。

```
【参考】@图片1 是主角本人，只用来锁定长相、发型与服装。首帧与尾帧的要求见文末。
【保持不变】同一角色、同一发型发色、同一服装与配色；背景是一整块均匀纯绿；镜头固定不动。

【画幅占位（必须先满足这一条，再谈动作）】
角色整体（含头顶头发、两侧发梢、手肘、膝盖、鞋尖与鞋跟）的高度只能占画幅高度的 55%~60%，
宽度不超过画幅宽度的 70%，水平居中。
画幅四条边各留出至少 15% 的纯绿空白：上、下、左、右都不许有任何身体部位碰到、贴近或超出画面边缘。
必须完整可见、不许被裁掉的部位：**头顶与整个发型（含两侧垂下的长发）、双手、膝盖、两只鞋**。
角色最低点（鞋底）到画幅底边之间必须还能看到一条绿色空白，不要把鞋子画在画面最底下。
宁可把角色画小一点，也不许顶满画幅。

【动作】角色侧坐在地上蜷成一团打盹：膝盖收在身前，双手合拢垫在脸侧当枕头，
蓝色长发自然垂在身体两侧、全部在画幅内，双眼闭合，身体随呼吸极轻微起伏。
全段只有呼吸这一种动作，头和肩膀随呼吸轻微起伏。
最后一帧必须与第一帧逐帧完全相同，可以直接循环播放、接缝处不跳。全程闭眼，禁止睁眼、禁止起身。

【按秒】0s 睡姿静止闭眼；0~1.5s 缓慢吸气、背部与肩线轻微抬起；1.5~3s 缓慢呼气回落；
3~4s 呼吸回到起始相位，姿态与第 0 秒逐帧重合。之后保持到结束。

【禁止】睁眼、起身、站立、走动；整体平移、缩放；镜头推拉、摇移、旋转；
姿势大幅变化；运动模糊与残影；绿幕上出现投影、地面线、光斑、渐变；
画面四角或边缘出现任何文字、字母、数字、logo、水印、色块、符号；Zzz 之类符号；画面加边框。
```

**这条的出图验收（不对就重抽，别拿去抠像）：**

- [x] 两只鞋完整，**鞋底下面还能看到一条绿**
- [x] 左右两侧垂下的长发都在画幅内，发梢没有贴着边缘断掉
- [x] 头顶上方有 ≥10% 画幅高度的绿（不是贴着顶边）
- [x] 四个角干净，没有小字/水印/色块
- [x] 角色只占画幅高度一半多一点（看起来"小"，不是"顶满"）
- [x] 背景是**均匀**纯绿，没有渐变、亮斑、地面阴影

### 出图不对时，直接追加这一句（豆包是对话式的）

| 出图问题 | 追加这句 |
|---|---|
| 还是顶满画幅 | 「把角色整体缩小，高度只占画幅的 55%，四周绿边加宽到 15% 以上」 |
| 鞋子被下边缘切 | 「镜头拉远，让两只鞋完整露出，鞋底下面必须留出一条绿色空白」 |
| 头发被左右边缘切 | 「镜头再拉远一点并把角色往中间挪，两侧垂下的长发必须完整在画幅内」 |
| 头顶贴着上边 | 「头顶上方要留出至少 15% 的绿色空白」 |
| 四角出现水印/小字 | 「去掉画面里所有的文字、水印和小图标，背景保持一整块纯绿」 |
| 角色看着像 4 头身 | 「头再大一圈、身体再缩短，做成 2.5 头身，头宽超过肩宽」 |
| 睡着了但姿势是躺平 | 「改成侧坐蜷成一团，膝盖收在身前，双手垫在脸侧，不要躺下」 |

## 11 `shy` 害羞


> ①「被身后提着后领」→ 别人的手；②「看不见的线」→ 提线木偶；③「失重悬浮、手臂张开」→ 宇航员；

> `--lift` 已实现（`pack --lift N` 整体上移 N 像素，不影响缩放）。实测 `--lift 70` 把底边
> 从 468 抬到 398。抬升量取 60~80px。
>
> 状态命名：**循环的那条登记成 `drag`**（拖动期间一直在播的就是它）；
> `drag_start` 是可选的一次性过渡。引擎侧目前 `AvatarState` 里**还没有 `drag`**，
> 要用它必须先加类型 + 在拖拽时切状态。

# 生成完之后的入库

> **豆包在绿幕上几乎一定会加两样东西**（提示词里已经禁了，但它经常不听）：
> 脚下的软投影、画面角落的「豆包AI生成」小字。
> 抽帧抠像之后**必须**先跑 `clean` 再去 `pack`，否则包围盒会被这两样撑大，
> 占位/尺寸的判断全是错的（实测被撑到占画幅 96%，清理后才是 63%）。

```bash
# 1) 抽帧（12fps 与现有素材一致）
mkdir -p tmp/wave
ffmpeg -i wave.mp4 -vf fps=12 tmp/wave/f%04d.png

# 2) 抠像（你的既有管线：PR 手工 / HSV 自动），透明 PNG 输出到 tmp/wave_keyed/

# 3) 入库：按锚图身高统一缩放 + 脚底基线对齐 + 自动切末尾静止帧 + 拼表 + 登记 frames.json
python scripts/avatar-sheet-tool.py pack \
  --from tmp/wave_keyed --state wave --fps 12 --auto-trim --write

# 4) 质检
python scripts/avatar-sheet-tool.py verify
```

`blink` 例外：不生成，直接从 `idle` 抽好的帧里挑一次闭眼，用 `apply` 的 `trim` 模式裁。
